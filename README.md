# Imbalanced-Classification-Model

## Built and optimized an XGBoost model for rare event detection in a highly imbalanced dataset (29 features), achieving 0.95 ROC AUC
Engineered 25+ interaction features  to capture nonlinear structure and improve predictive performance
Addressed class imbalance with SMOTETomek resampling and designed a full ML pipeline with stratified validation and low-FPR ROC optimization (max_fpr = 0.01)
